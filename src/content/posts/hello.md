This replaces a site that was really a resume with animations on it. Useful for about a
week, awkward to maintain, and not something I ever wanted to read.

What I actually wanted was an archive: a dated list of things I've built, each with
enough detail that I can remember the decisions later, and somewhere to write when a
problem turns out to be more interesting than it looked.

So: monospace, no JavaScript, one CSS file. Projects live in `/projects`, notes live
here in `/log`. Adding either one means writing a Markdown file.

Expect notes on rate limiting, prompt-injection defense, and the parts of building a
product for non-technical users that I got wrong the first time.
