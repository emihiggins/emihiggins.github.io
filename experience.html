Escapia GraphQL Rate-Limiting Service

A production, low-latency rate limiter for Escapia's federated GraphQL API and legacy SOAP reservation engine — ~323k requests/hour. Built on Node.js / Hapi backed by an AWS ElastiCache Valkey cluster, with a custom Lua script (EVALSHA) for atomic sliding-window limiting on multi-dimensional keys. Replaced a crash-looping predecessor and cut P99 latency 39.6% with zero post-deploy incidents.
