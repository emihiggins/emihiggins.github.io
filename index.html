Claude Code Token Optimizer

VS Code extension · published on the Marketplace

I use Claude Code every day and wanted to know exactly where my token spend was going. It writes detailed session transcripts to disk as raw JSONL — no dashboard, no cost summary — so I built a VS Code extension that reads them locally, runs a 10-rule detection engine (broad searches, cache-invalidating prompts, redundant reads, context-compaction waste, and more), and surfaces the most common ways I'm burning tokens with an estimated dollar amount recoverable for each, plus efficiency trends and per-session drill-downs. Fully local — no telemetry, no external calls. The data layer is a vscode-free, unit-tested TypeScript core (38 tests) behind an esbuild-bundled Chart.js webview with zero runtime dependencies.
